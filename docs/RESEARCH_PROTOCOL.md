# PLH Research Protocol

## Research contract

Before enabling a scheduler that uses PLH decisions, freeze:

- primary research questions,
- primary endpoints,
- baseline definitions,
- perturbation taxonomy,
- scheduler coefficients used in final experiments.

Protocol changes after the first comparative run must be recorded as amendments.

## Primary questions

1. Does need-first coordination degrade less under mid-run perturbations than role-first coordination?
2. Does it recover faster after worker/environment/assumption changes?
3. Does structural and later semantic spacing reduce accidental duplicated effort without suppressing deliberate independent verification?
4. Does situatedness improve assignment beyond capability-only selection?
5. Can fluid assignment preserve deterministic authority and evidence invariants?

## Baselines

- B0: strong single agent
- B1: static workflow / current ORCA-style routing
- B2: fixed specialist roles
- B3: dynamic assignment into predefined roles
- P: PLH

## Primary endpoints

- externally verified perturbed-task success
- recovery latency

## P0 claim discipline

P0 is observational only.

Allowed claims after P0:

- deterministic coordination-state projection implemented
- structural coverage/overlap/contention/evidence-gap metrics measured

Not allowed after P0:

- PLH improves task success
- PLH improves spacing
- Needs emerge dynamically
- agents switch responsibilities

Those require later phases and comparative experiments.
